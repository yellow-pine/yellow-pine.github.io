What we build

  • Latch grip-test your repo

    Scores a public GitHub repository two ways, for AI coding agents and for human newcomers. Six category scores, a one-line verdict on each, and a prioritized list of fixes with the score impact of each one.

  • kishi show up as the most you

    Turns a short onboarding into a personalized, sixteen-section dating-readiness kit, on the web and as a printable PDF. English, German and Turkish.

  • bly your career agent

    Runs a job search out of your own inbox, on your own machine. Free, open source, local-first.

  • zsh-github-dark a terminal that matches your editor

    A minimalist zsh and macOS Terminal setup with GitHub Dark colors, a git-aware prompt, and a one-line installer.

How we work

We serve language models on our own hardware, gate every pull request on a code review from a locally served model before it can merge, and build the tooling we need as we go. The pieces that turn out to be useful to other people get released.
