What we build

  • Latch latch.fyi Scores any public GitHub repository twice: once the way an AI coding agent reads it, once the way a human newcomer does. Then it lists the fixes worth making first.
  • bly Free to use bly.fyi Runs a job search out of your own inbox, on your own machine. Local-first, and free.
  • zsh-github-dark Open source A zsh and macOS Terminal setup that matches GitHub Dark, with a git-aware prompt and a one-line installer.

How we work

We serve our own language models on our own hardware. Every pull request is reviewed by one of them before it can merge, and no change reaches a product without passing that gate.

We build the tooling we need as we go. The pieces that turn out to be useful to somebody else get released.
